# Astro Adventure / 回声航路

一款单局制俯视角异星生存原型。玩家驾驶侦察员离开回声号营地，在 Khepri-9 的烬砂荒原上采集晶尘与深核，在怪物锁定自己时优先逃离，并依靠营地炮台挡住周期性袭来的地鸣兽群。

当前地图为 **7680 × 5120**，摄像机跟随玩家移动。场景是特定星球地表，不是太空；包含安全盆地、锈红荒原、深核矿区、陨坑、裂隙、岩脊、发光苔藓和地表尘雾。

## 核心循环

1. **近区起步**：营地附近只有低价值青色晶尘，足以建造基础炮台。
2. **主动布防**：靠近营地四周的炮位按 E 建造炮台；再次按 E 升级。
3. **深入荒原**：普通晶尘越远价值越高，紫色深核只生成在距营地约 2450 以上的危险带。
4. **风险采集**：环境怪物会主动发现并追击玩家。玩家基础速度和冲刺速度都明显快于大多数怪物。
5. **逃脱优先**：玩家没有持续射击武器。Shift 消耗体力冲刺，Space 发动无伤害应急脉冲，将近身怪物击退。
6. **回防守家**：波次来袭时，营地炮台自动迎战。远离营地时需要通过雷达和倒计时决定继续采集还是及时返回。
7. **深核升级**：三级炮台除晶尘外还强制消耗 1 枚深核，因此后期必须离开安全区。

清除五波后获胜；回声号耐久归零则失败。每波之间有约 38 秒的远征窗口。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` / 方向键 |
| 冲刺 | 按住 `Shift` |
| 应急脉冲击退 | `Space` |
| 建造 / 升级 / 修复 | `E` |
| 提前开始下一波 | `Enter` |
| 暂停 / 继续 | `Esc` |
| 结算后重新开始 | `R` |

应急脉冲不造成伤害，只消耗体力和冷却时间，用于创造逃跑空间。

## HUD

- 营地耐久、波次、当前星球、晶尘与深核数量
- 驾驶员生命、冲刺体力、应急脉冲冷却
- 全局区域雷达：营地、玩家、摄像机、资源、怪物和危险带
- 距离感知交互提示、波次倒计时、遭遇通知和胜负结算

## 当前内容

- 三种怪物：快速侦察体、高耐久重装体、远程喷吐体
- 进入警戒圈后主动锁定玩家；超出牵引距离后返回原活动区域
- 四座独立自动炮台，三级成长，三级升级需要深核
- 近区、远区普通晶尘与远端深核资源分布
- 环境怪物持续活动，并会缓慢补充
- 动态相机、地形细节、弹道、命中、粒子和程序化音效
- 暂停、失败、胜利与快速重开流程

## 运行

要求 Godot 4.7 或兼容的 4.7.x 版本。

```bash
godot --path .
```

无窗口验证：

```bash
godot --headless --path . --editor --quit
godot --headless --path . --quit-after 120
godot --headless --path . --script tests/runtime_smoke.gd
godot --headless --path . --script tests/gameplay_balance.gd
```
